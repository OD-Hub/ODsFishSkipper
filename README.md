# OD's Fish Skipper

Tired of grinding every single fish for the **Master Angler** achievement? This mod lets you **instantly mark all fish as caught** with a single button press.

## Features

- Press **F9** (configurable) to instantly flag every fish in the game as caught.
- Unlocks the **Master Angler** achievement immediately.
- Supports **Generic Mod Config Menu** for easy key rebinding.
- Lightweight — zero performance impact.

## Installation

1. Install [SMAPI](https://smapi.io/).
2. Download and unzip this mod into `Stardew Valley/Mods/OD's Fish Skipper`.
3. Launch the game via SMAPI.

## Configuration

Edit `config.json` to change the activation key:

| Setting      | Default | Description                     |
|-------------|---------|---------------------------------|
| `UnlockKey` | `F9`    | The keybind to trigger the mod. |

If you have **Generic Mod Config Menu** installed, you can also change the key from the in-game mod menu.

## Usage

Press the configured key (default: **F9**) — all fish are immediately marked as caught and the achievement pops.

## Compatibility

- Stardew Valley 1.6+
- SMAPI 4.0.0+
- Single-player only (achievements are disabled in multiplayer).
